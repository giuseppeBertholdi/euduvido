# euduvido

**Eu Duvido!**: jogo de festa de estimativa e blefe (como o Nem a Pato). Aparece uma pergunta com resposta numérica; cada um, na sua vez, aumenta o lance ("é X ou mais") ou grita "eu duvido!". Errou, perde um "!". O último que sobrar ganha.

- `app/`: o app (Expo / React Native, roda no Expo Go) e o backend do online (Supabase: migrations e Edge Functions). Veja **[app/README.md](app/README.md)** pra rodar, testar e publicar.
- `design_handoff_eu_duvido_gamba/`: o handoff de design original (direção "Gambá", antes da marca virar o "!").
